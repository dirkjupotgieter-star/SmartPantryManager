# Smart Pantry Manager

Smart Pantry Manager is a Java Android application created for Mobile App Development 700.

## Features

- Add pantry ingredients
- Edit pantry ingredients
- Delete pantry ingredients
- Store separate ingredient batches
- Track expiry dates
- Show expiring ingredients
- Suggest recipes based on pantry contents
- View recipe details
- Save settings

## Technologies Used

- Java
- Android Studio
- XML
- SQLite
- SharedPreferences
- ListView
- Custom Adapter
- Intents

## Database

The app uses SQLite with two main tables:

- Pantry
- Recipes

SQLite was used because the app needs to work offline and keep data saved after the app closes.
